Sistema de Administración para Asesores

¿Cómo funciona este sistema?

  • Folio único: Cada caso recibe automáticamente un folio único que identifica el registro de forma exclusiva.
  • Registro de víctimas: Complete los campos de NOMBRES y APELLIDOS de la víctima. El sistema no permite registrar el mismo cliente dos veces.
  • Información del caso: Ingrese todos los datos del fraude: tipo, licenciado asignado, montos de recuperación, indemnización, penalización, total a entregar, pago pendiente y concepto de pago.
  • Validación automática: El sistema valida que no existan clientes duplicados antes de guardar el caso.
  • Consulta de folios: Los clientes pueden consultar su caso ingresando el folio en la página principal del portal.

Complete todos los campos requeridos (*) para registrar exitosamente un caso de fraude.
